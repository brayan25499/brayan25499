## ⭐ Proyecto principal

### 🏋️ LevelUpGym

**LevelUpGym** es una plataforma web para la gestión de un gimnasio, desarrollada como proyecto académico durante mi formación en ADSO.

El proyecto integra funcionalidades de frontend, backend, autenticación, gestión de usuarios, membresías, pagos y seguimiento del progreso de los usuarios.

**Tecnologías principales:**

* Angular
* TypeScript
* C#
* ASP.NET Core
* Entity Framework Core
* SQL Server / Supabase
* JWT
* REST API
* Git & GitHub

### 🔑 Funcionalidades

* Registro e inicio de sesión
* Recuperación de contraseña
* Autenticación y validación de usuarios
* Gestión de membresías
* Cambio de planes
* Gestión de pagos
* Sesiones de entrenamiento
* Gestión de objetivos
* Seguimiento del progreso
* Perfil del usuario
* Panel administrativo
* Exploración de músculos y ejercicios
* Integración con servicios externos
* Despliegue de frontend y backend
